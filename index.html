How to use

Click empty space to create a 100 price box.

Click a box to select it.

Click the selected box again to edit the number.

Simply type the new number.

Press Enter to finish.

Shift + click to select multiple boxes.

Drag a selected box to move all selected boxes.

Drag the blue corner of the group to resize all selected boxes.

Press Delete or Backspace to delete selected boxes.
