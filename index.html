How to use

Click empty space to create a price box.

Every new box starts at 100.

Type directly when a box is selected to change its number.

Press Enter when finished typing.

Drag empty space around several boxes to select them together.

Drag a selected box to move all selected boxes together.

Shift + click boxes to add/remove them from the selection.

Drag the blue corner to resize selected boxes together.

Press Delete or Backspace to delete selected boxes.

Double-click a box if you want to select it and immediately edit its number.
